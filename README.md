# Node API ORM Starter

A lightweight Node.js + TypeScript starter kit featuring an Eloquent-style ORM, fluent routing system, middleware aliasing, modular providers, and multi-driver caching.

Supports both SQL and MongoDB backends with a clean Laravel-inspired developer experience.

## Features

- Express + TypeScript
- Eloquent-style ORM & Query Builder
- Relations, scopes, eager loading, events & soft deletes
- Fluent RouterBuilder with groups, prefixes, resources & model binding
- Middleware aliases & parameterized middleware factories
- Multi-driver cache system (file, database, redis)
- Optional APP_KEY encryption support
- Modular service providers & application bootstrapping
